Winky · Multi-Agent Cursor Companion

从目标到执行：软硬件协同的多步骤桌面控制机器人。

Winky 是一套面向无障碍语音交互的软硬件协同系统：AI 先理解目标，再读取桌面状态、规划多步骤操作、控制电脑完成执行，并让实体机器人同步转向、播报和反馈。它把桌面控制从“找到一个按钮”推进到可追踪、可恢复的连续任务流程。项目入围天猫 AI 黑客松科技 UI 赛道前三强，并进入机器人仿人技术大赛决赛。

Problem Framing

复杂任务的难点，不是找到一个入口，而是连续完成一整组操作。

用户面对复杂软件时，往往需要在多个窗口、菜单和输入状态之间连续切换。Winky 把任务拆解、桌面感知、电脑控制、硬件反馈和异常恢复串成一条可追踪的执行链。

任务理解

用户只需要说出目标，例如“整理这批文件并完成归档”，系统先把自然语言目标拆解成可执行、可校验的多步骤操作计划。

视觉定位

视觉 Agent 理解当前屏幕，识别按钮、菜单、输入框等 UI 元素，把抽象意图映射到具体目标区域。

具身引导

光标高亮、机器人语音、表情、眨眼和视线方向共同给出反馈，让用户知道下一步在哪里、为什么这么做。

Project Flow

从用户目标，到 Agent 协同，再到可感知的桌面引导。

01

用户提出目标

用户不需要描述界面结构，只需要说出想完成的任务，例如找入口、改设置、完成某个办公软件操作。

02

意图 Agent 分析需求

系统判断用户真正要完成的结果，生成步骤、前置条件、确认点和异常分支，而不是只给一段笼统教程。

03

视觉 Agent 定位目标

多模态视觉模型理解当前屏幕，识别目标 UI 元素的位置，将操作意图落到具体坐标和界面区域。

04

光标与机器人共同引导

桌面控制层执行点击、输入、窗口切换等动作；机器人通过语音、表情、眨眼和视线方向同步反馈进度，用户可以随时打断、确认或恢复任务。

Architecture

多 Agent 协同，把复杂界面变成可跟随的操作路径。

Winky 的核心价值在于把传统“人理解界面、寻找操作”转变为“AI 理解任务、引导人完成操作”。适用于办公软件辅助、教育学习指导、老年人与新手数字化帮助等场景。

视觉 Agent：看懂当前屏幕

多模态视觉 API 负责理解屏幕内容，识别目标按钮、菜单、文件、输入框等 UI 元素，并输出可用于光标引导的空间位置。
